# CampusCare AI 🎓

**An AI-Powered Campus Complaint Management System**

CampusCare AI is a web-based application designed to simplify campus issue reporting and complaint management. It helps students submit complaints, track their status, and provide feedback while enabling administrators to manage and prioritize issues efficiently.

## ✨ Features

* 📝 **Complaint Reporting** — Submit campus-related issues.
* 🤖 **AI-Assisted Analysis** — Analyze complaints to support efficient handling.
* 📊 **Admin Dashboard** — Manage and monitor reported complaints.
* 🔍 **Complaint Tracking** — Track complaint status and progress.
* ⭐ **Feedback System** — Rate resolved complaints and provide feedback.
* 🗺️ **Campus Heatmap** — Visualize campus issues by location or category.
* 🔔 **Notifications** — Support complaint-related notifications.
* 💬 **Campus Assistant** — Provide assistance with campus-related queries.

## 🚀 Getting Started

### Prerequisites

Install [Node.js](https://nodejs.org/) and npm on your computer.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/VarshithaRam28/CampusCare-AI.git
   ```

2. Navigate to the project directory:

   ```bash
   cd CampusCare-AI
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Configure environment variables if required by the application. Refer to `.env.example` and use your own credentials. Never publish real API keys or secrets.

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open the local URL shown in your terminal.
